Public and Management edit the detail page. Search is one page with three drop areas: Search for, Narrow with, and Show in the list. CM fields and Atlantis elements stay separate. Add field opens a dialog. The records and the code are illustrative.

CM fields

On a detail tab, drop a field into the page or into a table cell. On Search, drop it where a searcher should use it.

Elements

Separate from CM fields. Set the attributes on the placed element. Nested content goes in the slots.
